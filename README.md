# Flask SQLAlchemy Workout Application Backend

## Project Description

This project is a RESTful backend API for a workout tracking application. It is built with Flask, SQLAlchemy, Flask-Migrate, SQLite, and Marshmallow.

The application allows trainers to create, view, and delete workouts and exercises, as well as associate exercises with workouts while recording sets, reps, and duration.

## Technologies

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Migrate
- Marshmallow
- SQLite
- Pipenv
- Pytest
